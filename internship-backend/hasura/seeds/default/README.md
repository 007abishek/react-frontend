This folder stores SQL seed files applied via `restore-hasura.ps1`.

Current flow:
1. Generate product seed SQL:
   - `npm run seed:generate`
2. Apply metadata + seed:
   - `powershell -ExecutionPolicy Bypass -File .\restore-hasura.ps1`

`products_seed.sql` is auto-generated by:
- `src/scripts/generateHasuraSeed.ts`
